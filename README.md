  in Kyiv; one killed, five hurt; Europe says it is ready for talks
  with Moscow.

- **The Gulf:** Houthi missiles hit Riyadh; the Saudi sovereign wealth
  fund's PIF Tower is damaged.
- **Markets:** Anthropic's value reportedly hits $1.5tn after its
  record $81.3bn IPO, priced at $83.
- **Culture:** GTA VI sales pass $1.80bn — already past The Odyssey's

- **Also today:** Voyager 1 reaches one light-day from Earth, Cyclone
  Akvan nears Odisha with 300,000 evacuated, Israel's Gaza ground

  uranium enrichment at Yongbyon.

All stories were reported on 20 November 2026.

## How it runs

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` to `/output/entry.png`. No network, no randomness — two runs
write byte-identical output. The image was drawn in code with Pillow;
the drawing script is kept alongside the bundle as `render.py`.
